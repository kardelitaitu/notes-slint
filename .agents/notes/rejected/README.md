# rejected

Ideas we decided **against**, with the reason. The reason is the entire point of this
folder.

- Frontmatter `status: rejected`.
- Record: what was proposed, why it was rejected, and **what would change the answer**.
  A rejection without a re-opening condition is a grudge, not a decision.
- Rejected ideas get re-proposed. This is the only reason to keep them. **Check here before
  building or arguing for anything.**
- A rejection is not an ADR, but a significant one should have a matching
  `docs/decisions/` entry so it shows up in the decision history.
- If a rejection turns out to have been wrong, move the note to `../proposed/` with the new
  evidence appended, and note in the body that it was re-opened and why.
