# implemented

Things that are **actually built**. Not "agreed to" — built, working, in the tree.

- Frontmatter `status: implemented`.
- Document how it works *now*, including where reality diverged from the original proposal.
  The divergence is the valuable part; a note that merely restates the plan is worthless
  once the code exists.
- Cite the files that implement it, e.g. `crates/core/src/save.rs`.
- Read the relevant note here **before** changing that area of code — it carries the
  reasoning the code cannot express.
- If the feature is later removed or replaced, move the note to `../archived/`.

Until the M0 spike completes and the first code lands, this folder is legitimately empty.
